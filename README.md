# Информационная система школы подготовки к ЕГЭ/ОГЭ

Дипломный проект: полнофункциональная информационная система школы подготовки к ЕГЭ и ОГЭ — сайт с личными кабинетами, материалами курсов, тестами, расписанием и внутренней системой сообщений.

## Возможности

- **4 роли с разными правами**: ученик, родитель, учитель, администратор
- **Кабинет ученика**: материалы своего курса (9–11 классы, PDF и внешние ссылки), тесты, домашние задания, прогресс-бар, календарь занятий с выбором недели
- **Кабинет родителя**: статистика и успеваемость ребёнка
- **Учителя и администраторы**: добавление и редактирование материалов, управление курсами, отчёты
- **Внутренние личные сообщения** между пользователями платформы
- **Регистрация** (публичная или по приглашениям — настраивается через переменные окружения)

## Стек

- **Back-end**: Python, Flask, SQLAlchemy
- **База данных**: MySQL (PyMySQL)
- **Front-end**: HTML-шаблоны Jinja2
- **Безопасность**: session hardening (HttpOnly, SameSite), контроль доступа на уровне ролей

## Запуск

1. Клонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   python -m venv venv && source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Создайте базу данных MySQL `eg_ege_school`
3. Настройте переменные окружения (при необходимости скопируйте шаблон в `.env`):
   ```
   SECRET_KEY=<секретный ключ>
   DATABASE_URL=mysql+pymysql://user:password@localhost:3306/eg_ege_school
   ALLOW_PUBLIC_REGISTRATION=true
   ```
4. Запустите приложение.

## Структура

- `app/` — приложение Flask: модели (`models.py`), маршруты (`routes.py`, `manage_routes*.py`), формы (`forms.py`), безопасность (`security.py`)
- `config.py` — конфигурация и переменные окружения
